# Бібліотека — як поставити на телефон

## Що в папці

```
index.html               ← сам застосунок (шрифти вбудовані, інтернет для них не потрібен)
manifest.json            ← назва, іконка, колір — телефон читає це при встановленні
sw.js                    ← офлайн-режим
owl-spring.png           ← сова-маскот, весна
owl-summer.png           ← літо
owl-autumn.png           ← осінь
owl-winter.png           ← зима
icon-192.png             ← іконки для робочого столу
icon-512.png
icon-maskable-192.png
icon-maskable-512.png
apple-touch-icon.png
favicon.png
```

Усі файли лежать поруч, без вкладених папок — так їх можна завантажити на GitHub одним махом.

## Встановлення через GitHub Pages

Застосунок живе в репозиторії `library_app`. Щоб телефон дав його встановити
з іконкою, файли мають відкриватися за адресою `https://…`:

1. На GitHub: репозиторій → **Settings → Pages**
2. Source: гілка `main`, папка `/ (root)` → **Save**
3. За хвилину-дві зʼявиться адреса виду `https://…github.io/library_app/`
4. Відкрий її в Chrome на телефоні → меню (⋮) → **«Встановити застосунок»**

Якщо Chrome пише «вже встановлено» і не дає поставити (так буває з адресою
`nataliatronza.github.io`), застосунок треба перенести на окрему адресу —
власну безкоштовну організацію на GitHub з репозиторієм `<назва>.github.io`,
як зроблено для Стежки.

Перевірка: **Я → На телефон → Офлайн-режим** має показувати «готово ✓».

## Що вміє застосунок

- **Полиця.** Книжки стоять обкладинками вперед, по вкладках: усі / читаю /
  у планах / прочитані. Коли ряд заповнюється, знизу додається нова полиця.
- **Пошук у базі книжок.** У формі нової книги почни вводити назву — застосунок
  знайде видання в Google Books і Open Library та сам підтягне обкладинку
  й автора. Для книг, доданих раніше, у картці книги є «Знайти обкладинку».
  Пошук потребує інтернету.
- **Сова-читачка.** Сидить у шапці з реплікою і на полиці серед книжок.
  Вбрання змінюється з порою року (весна — вінок, літо — капелюх,
  осінь — окуляри й шарф, зима — шапка). Тапни по ній — скаже щось нове.
  Імʼя змінюється в розділі «Я».
- **Нічна тема.** З 22:00 до 6:00 застосунок сам темнішає й засвічує зірки,
  як Стежка. Вимикається в розділі «Я».
- **Рівні.** Кожні 5 прочитаних книг — новий читацький рівень.
- **Монети й крамниця.** 15 монет за прочитану книгу; за них купуються
  предмети на полицю. Свої предмети з власними цінами — остання картка в крамниці.
- **Кольори.** Шість палітр, плюс власні картинки для фону й полиць.

## Про твої дані

Книги, монети, предмети й картинки зберігаються **в памʼяті телефона**,
всередині застосунку, і нікуди не відправляються. Якщо почистити дані Chrome,
видалити застосунок або змінити телефон — бібліотека зникне.

Тому в розділі **Я → Резервна копія** є дві кнопки: «Зберегти копію» і
«Відновити». Зроби копію одразу після того, як внесеш перші книги, і потім
раз на кілька місяців. Файл можна тримати в Google Drive.

## Оновлення

Після кожного оновлення у файлі `sw.js` змінюється рядок
`CACHE_VERSION = "biblioteka-v3"` (v4, v5…), інакше телефон показуватиме
стару версію з памʼяті. На телефоні нова версія підхоплюється з другого
відкриття застосунку. Книги при оновленні лишаються на місці.

Нова іконка на робочому столі може зʼявитися не одразу — Android оновлює
іконки встановлених застосунків сам, інколи через кілька днів. Щоб побачити
її відразу, видали застосунок і встанови знову (спершу збережи копію бібліотеки!).
