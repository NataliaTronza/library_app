# Моя бібліотека — як поставити на телефон

## Що в папці

```
biblioteka/
├── index.html                 ← сам застосунок
├── manifest.json              ← назва, іконка, колір — телефон читає це при встановленні
├── sw.js                      ← офлайн-режим
├── icon-192.png               ← іконки для робочого столу
├── icon-512.png
├── icon-maskable-192.png
├── icon-maskable-512.png
├── apple-touch-icon.png
└── favicon.png
```

Файли мають лежати саме так, поруч один з одним. Якщо перекласти `index.html`
в іншу папку окремо — іконка й офлайн перестануть працювати.

---

## Важливо знати наперед

Щоб телефон дозволив встановити застосунок з іконкою, файли треба відкривати
за адресою `https://…`. Просто скинути папку на телефон і відкрити файл
недостатньо — Android у такому разі зробить звичайну закладку, без іконки
й без офлайну.

Тому папку треба один раз десь розмістити. Це безкоштовно і робиться за
кілька хвилин. Нижче два способи.

---

## Спосіб 1: Netlify Drop (найшвидший, без реєстрації)

1. На компʼютері зайди на **app.netlify.com/drop**
2. Перетягни туди всю папку `biblioteka`
3. За кілька секунд зʼявиться адреса виду `https://якесь-слово.netlify.app`
4. Відкрий цю адресу в Chrome на телефоні
5. Меню (⋮) → **«Встановити застосунок»**
6. Іконка з полицею книг зʼявиться на робочому столі

Адресу збережи — вона знадобиться, якщо колись захочеш оновити застосунок
(просто перетягнеш нову папку).

Без реєстрації посилання живе обмежений час. Якщо створити безкоштовний
акаунт — залишиться назавжди.

---

## Спосіб 2: GitHub Pages (назавжди, потрібен акаунт)

1. Створи безкоштовний акаунт на github.com
2. Новий репозиторій → назва, наприклад, `biblioteka` → Public
3. Завантаж усі файли з папки (кнопка «uploading an existing file»)
4. Settings → Pages → Source: `main`, папка `/root` → Save
5. За хвилину-дві зʼявиться адреса `https://твій-нік.github.io/biblioteka/`
6. Далі так само: Chrome на телефоні → меню (⋮) → «Встановити застосунок»

---

## Перевірка, що все вийшло

Відкрий застосунок → **Налаштування** → внизу розділ «Встановити на телефон».
Там є рядок **«Стан офлайн-режиму»**:

- **готово ✓** — усе працює, можна вимикати інтернет
- **недоступний** — файли відкриті не за адресою `https://`, дивись розділ вище

---

## Про твої дані

Книги, монети, куплені предмети й завантажені картинки зберігаються
**в памʼяті телефона**, всередині застосунку. Вони нікуди не відправляються.

Але це означає: якщо почистити дані Chrome, видалити застосунок або
змінити телефон — бібліотека зникне.

Тому в **Налаштуваннях → Резервна копія** є дві кнопки:

- **Зберегти копію** — завантажує файл з усіма книгами
- **Відновити з копії** — повертає все назад із такого файлу

Зроби копію одразу після того, як внесеш перші книги, і потім
раз на кілька місяців. Файл можна тримати в Google Drive або надіслати собі.

---

## Якщо захочеш оновити застосунок

Коли я зроблю нову версію, треба буде:

1. Замінити файли на хостингу
2. У файлі `sw.js` змінити рядок `CACHE_VERSION = "biblioteka-v1"` на `v2`
   (інакше телефон показуватиме стару версію з памʼяті)
3. На телефоні закрити застосунок і відкрити знову

Твої книги при оновленні залишаються на місці.
