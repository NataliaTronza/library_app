# Бібліотека — як поставити на телефон

## Що в папці

```
index.html               ← сам застосунок
fonts.css                ← шрифти (вбудовані, інтернет для них не потрібен)
manifest.json            ← назва, іконка, колір — телефон читає це при встановленні
sw.js                    ← офлайн-режим
owl-spring.png           ← сова-маскот, весна
owl-summer.png           ← літо
owl-autumn.png           ← осінь
owl-winter.png           ← зима
item-candle-slowdays.png ← свічка «Slow days» для крамниці
owl-icon-192.png         ← іконки для робочого столу (сова)
owl-icon-512.png
owl-icon-maskable-192.png
owl-icon-maskable-512.png
apple-touch-icon-owl.png
favicon-owl.png
```

Усі файли лежать поруч, без вкладених папок.

## Встановлення через GitHub Pages

Застосунок живе в репозиторії `library_app`:

1. На GitHub: репозиторій → **Settings → Pages**
2. Source: гілка `main`, папка `/ (root)` → **Save**
3. Адреса: `https://nataliatronza.github.io/library_app/`
4. Відкрий її в Chrome на телефоні → меню (⋮) → **«Встановити застосунок»**

Якщо Chrome пише «вже встановлено» і не дає поставити (так буває з адресою
`nataliatronza.github.io`), застосунок треба перенести на окрему адресу —
власну безкоштовну організацію на GitHub з репозиторієм `<назва>.github.io`,
як зроблено для Стежки:

1. github.com → свій аватар → **Your organizations → New organization** → план **Free**.
   Назва, наприклад, `biblioteka-natalia`.
2. В організації створити **публічний** репозиторій з назвою
   `biblioteka-natalia.github.io` (точно як назва організації + `.github.io`).
3. Дати Claude доступ до цієї організації (так само, як для Стежки).
4. Claude закладає туди файли, і застосунок відкривається за адресою
   `https://biblioteka-natalia.github.io/`.
5. **Перед переїздом:** у старому застосунку **Я → Резервна копія → Зберегти копію**.
   Потім встановити застосунок з нової адреси й там **Я → Резервна копія → Відновити**.
   Дані привʼязані до адреси, тож самі вони не переїдуть.

Перевірка: **Я → На телефон → Офлайн-режим** має показувати «готово ✓».

## Пошук книжок

Коли додаєш книгу, почни вводити назву — застосунок шукає одночасно в кількох місцях:

- **Yakaboo** — каталог української книгарні: свіжі переклади, українські видання,
  рідні обкладинки, рік видання й жанр. Якщо книжка є паперовою й електронною,
  береться паперове видання. Це внутрішній пошук сайту Yakaboo: якщо книгарня
  колись його змінить, цей пункт перестане відповідати, а решта джерел працюватиме.
- **Українська Вікіпедія** — головне джерело для українських книжок і перекладів.
  Звідти беруться обкладинка, автор і рік. Шкіл, фільмів і письменників
  у результатах не буде — лишаються тільки книжки.
- **Open Library** — запасне джерело, переважно англомовні видання.
- **Google Books** — знає найбільше видань, але без власного ключа зараз
  відмовляє всім (його безкоштовний спільний ліміт вичерпаний).

### Як отримати ключ Google Books (необовʼязково)

1. Зайди на console.cloud.google.com під своїм Google-акаунтом
2. Створи проєкт (будь-яка назва, наприклад «biblioteka»)
3. **APIs & Services → Library** → знайди **Books API** → **Enable**
4. **APIs & Services → Credentials → Create credentials → API key**
5. Скопіюй ключ (починається з `AIza…`) і встав у застосунку: **Я → Пошук книжок**
6. Бажано обмежити ключ: у налаштуваннях ключа **Website restrictions** →
   додай `nataliatronza.github.io/*`. Тоді ним не зможе скористатися ніхто інший.

Ключ безкоштовний, ліміт — тисяча пошуків на день.

## Що вміє застосунок

- **Зараз читаю.** На головному екрані — книжка, яку читаєш зараз, і скільки
  днів ти з нею. Кнопка «Прочитала ✓» одразу ставить штамп і відкриває оцінку.
- **Полиця.** Книжки стоять обкладинками вперед. Закладка зверху: жовта — «читаю»,
  червона — «у планах». Вкладки: усі / читаю / у планах / прочитані.
- **Перестановка.** Утримай книжку чи предмет пальцем ~пів секунди — він «зніметься» з полиці.
  Веди її, куди треба: сусідні книжки розсунуться, а латунна риска покаже місце.
  Біля верхнього чи нижнього краю екрана сторінка прокручується сама.
  Порядок зберігається. Звичайний тап, як і раніше, відкриває картку.
- **Оцінка.** Від 1 до 10 зірочок, плюс детальна оцінка по 5-бальній шкалі:
  сюжет, персонажі, стиль, фінал, вау-ефект, і яка вона — смішна, емоційна,
  затишна, напружена, пікантна. Змінити можна в картці книги.
- **Статистика.** Мета на рік з графіком (випереджаєш чи відстаєш і який темп
  потрібен), книжки по місяцях, жанри, оцінки, найкращі книги, портрет твого
  читання, цікаві факти. Перемикання між роками й «Усі роки».
- **Жанри.** Книжці можна дати кілька жанрів одразу. Свій жанр («+ свій» у формі
  або **Я → Мої жанри**) лишається у списку назавжди. Якщо прибрати його зі списку,
  книжки, яким він уже стоїть, його збережуть. У діаграмі жанрів книжка з кількома
  жанрами рахується в кожному.
- **Дати — за бажанням.** Для прочитаної книжки: «Знаю дати» (початок можна
  пропустити), «Лише рік» або «Не памʼятаю». Застосунок запамʼятовує останній
  вибір — зручно, коли вносиш багато старих книжок підряд. Книжки без дати
  видно в статистиці «Усі роки» (рядок «без дати»), книжки з роком — у своєму році,
  але не в графіку по місяцях.
- **Каталожна картка.** Тап по книжці — вона висувається з полиці й перелітає
  в картку з полями, твоїми враженнями й штампом «ПРОЧИТАНО». Поки картка відкрита,
  на полиці порожнє місце; закриваєш — книжка повертається. Номер картки сталий —
  перестановка книжок на полиці його не змінює.
- **Цитати.** У картці книжки: «Цитати → + додати». Усі разом — **Я → Мої цитати**.
  Сова іноді пригадує одну з них у своїй репліці.
- **Плани: «Є вдома» і «Хочу купити».** Вибирається у формі запланованої книжки.
  Книжка, яку хочеш купити, стоїть на полиці напівпрозорою з ярличком «купити».
  У вкладці «У планах» — фільтр «Є вдома / Хочу купити», у картці — кнопка
  «Купила — тепер удома».
- **Сова обирає.** Коли нічого не читаєш — кнопка на головній («Совуня, обери»),
  а також у вкладці «У планах». Сова тягне жереб із книжок, які є вдома.
- **Значки.** 17 значків (перша книжка, 3 книжки за місяць, мета року, нічна сова,
  Slow days…) — у статистиці внизу. За кожен — бонусні монети. Значки за вже
  прочитане відкриваються одразу.
- **Читацький рік.** У статистиці обраного року — банер «Читацький рік»: сторіз
  з підсумками (скільки прочитала, місяць, жанр і книжка року, твій портрет, рядок
  року). Наприкінці — картинка 1080×1920, щоб поділитися чи зберегти. Обкладинки
  з каталогів для неї завантажуються через відкритий сервіс картинок wsrv.nl
  (інакше браузер не дає їх намалювати); якщо він недоступний — замість обкладинки
  буде кольоровий корінець із назвою.
- **Сова-читачка.** Живе в шапці формуляра (на полицю її можна посадити в розділі «Я»). Дихає, кліпає, нахиляє голову, підстрибує від дотику.
  Коли щось читаєш — тримає розгорнуту книжку й гортає сторінки. Влітку замість
  кліпання по окулярах пробігає відблиск. Довкола сови падають листочки, сніжинки
  чи пелюстки — залежно від пори року. Поки полиця порожня — спить.
- **Вечір при лампі.** З 22:00 до 6:00 кімната темнішає, у кутку світить лампа —
  книжки біля неї теплі й світлі, далі — у тіні.
- **Живий інтерʼєр.** Стіна — окремий дальній шар: при прокрутці вона відстає
  від полиць, а при нахилі телефона зсувається разом із тінями. Удень по кімнаті
  повільно пливуть сонячні зайчики з вікна (надвечір — теплі). Вимикається в
  **Я → Кольори → Живий інтерʼєр**; якщо в телефоні ввімкнено «Зменшити рух» —
  вимикається саме.
- **Рівні.** Кожні 5 прочитаних книг — новий рівень, прогрес показують корінці.
- **Монети й крамниця.** 15 монет за прочитану книгу. У крамниці — свічка «Slow days»
  і твої власні предмети (картка «Свій предмет»: своя картинка й своя ціна).
  Новий предмет стає на полицю у випадкове місце — потім його можна пересунути.
- **Кольори.** Шість палітр, плюс власні картинки для фону й полиць.

## Про твої дані

Книги, монети, предмети й картинки зберігаються **в памʼяті телефона**.
Якщо почистити дані Chrome, видалити застосунок або змінити телефон —
бібліотека зникне. Тому: **Я → Резервна копія → Зберегти копію**,
раз на кілька місяців. Файл можна тримати в Google Drive.

## Оновлення

Після кожного оновлення у `sw.js` змінюється `CACHE_VERSION = "biblioteka-v13"`
(v14, v15…). На телефоні нова версія підхоплюється з другого відкриття.
Книги при оновленні лишаються на місці.
